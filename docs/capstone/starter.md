# Capstone Starter Template Guidance

A minimal starter layout will be provided under `labs/` (or a separate template repository). Students should:

1. Fork or copy the starter.
2. Replace the placeholder skills with real implementations.
3. Wire the chosen storage backend.
4. Extend the golden dataset if desired.
5. Ensure the Cloud Build / GitHub Actions quality gate passes.

## Suggested Directory Layout for Student Projects

```
dfd-compliance-evaluator/
├── src/
│   ├── skills/
│   ├── router/
│   ├── retrieval/
│   └── evaluation/
├── tests/
├── data/
├── terraform/ or scripts/
├── cloudbuild.yaml
└── README.md
```

Detailed starter code will be added as the course materials mature.
